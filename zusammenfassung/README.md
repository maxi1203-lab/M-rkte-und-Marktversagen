# Zusammenfassung

Eigene, kapitelweise Zusammenfassung als zentraler Lern-Kern.

- [`kapitel/`](kapitel/) — pro Kapitel eine `.md`-Datei nach Template.
- [`formelsammlung/`](formelsammlung/) — zentrale Formeln, eine Datei pro Thema.
- [`definitionen/`](definitionen/) — Begriffe & Definitionen, alphabetisch.

## Kapitel-Template (siehe auch CLAUDE.md)

```
# Kapitel X — Thema

## Worum geht's (1 Absatz)

## Kernbegriffe

## Modell(e): Annahmen, Gleichgewicht, Wohlfahrt

## Typische Klausuraufgaben

## Stolpersteine
```
