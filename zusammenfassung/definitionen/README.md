# Definitionen

Alphabetische Begriffs-Liste. Eine Datei pro Anfangsbuchstaben-Gruppe
(`a-e.md`, `f-k.md`, ...) **oder** eine Gesamtdatei `glossar.md` —
was dir leichter fällt.

## Format

```
### Externalität
Effekt des Handelns eines Akteurs auf die Nutzenfunktion eines anderen,
der nicht über den Markt internalisiert wird. Vgl. VO Einheit X, Folie Y.
```
