Definition: Externalität



    Eine Externalität tritt auf, wenn Nutzen oder Produktionsmöglichkeit eines
    Wirtschaftssubjekts direkt vom Verhalten anderer beeinflusst wird, ohne dass
    hierfür Kosten getragen oder Entschädigungen gezahlt werden.
        Beispiel für eine Externalität: Eine Stahlfabrik verschmutzt einen FLuss, der auch für
        Freizeitaktivitäten zugänglich ist.
        Kein Beispiel für eine Externalität: Eine Stahlfabrik verbraucht viel Strom und dadurch
        erhöht sich der Strompreis für andere Kunden.


    Externalitäten sind ein wichtiges Beispiel für Marktversagen.

    Das Marktgleichgewicht ist ineffizient, d.h. das Erste Wohlfahrtstheorem gilt
    nicht, wenn Externalitäten vorhanden sind.

Ökonomische Konzepte zur Identifizierung von Externalitäten:

    Bei Externalität durch Produktion
         private Grenzkosten (PMC): direkte Kosten des Produzenten, um eine zusätzliche
         Einheit eines Guts zu produzieren.
         Grenzschaden (marginal damage, MD): alle zusätzlichen Kosten, die anderen durch
         die Produktion des Guts auferlegt werden, die aber nicht vom Produzenten getragen
         werden
         soziale Grenzkosten (social marginal cost, SMC = PMC+MD):
         private Grenzkosten plus Grenzschaden.
    Bei Externalität durch Konsum:
         privater Grenznutzen (private marginal benefit, PMB): direkter Nutzen des
         Konsumenten vom Konsum einer zusätzlichen Einheit eines Guts
         Grenzschaden (marginal damage, MD): alle zusätzlichen Schäden, die anderen durch
         den Konsum des Guts auferlegt werden, die aber nicht vom Konsumenten getragen
         werden
         sozialer Grenznutzen (social marginal benefit, SMB):
         privater Grenznutzen minus Grenzschaden.

Einfaches Modell mit Externalitäten



   Ein Markt im vollständigen Wettbewerb.
   Der repäsentative Produzent produziert Gut x mit Kosten c (x ).
   Gut x wird zum Preis p verkauft.
   Die Produktion von x Einheiten generiert S (x ) = x Einheiten an
   Umweltverschmutzung.
   Der repäsentative Konsument ist mit Einkommen m ausgestattet und hat folgende
   Nutzenfunktion über Gut x und Numeraire y (z.B. Geld):

                                            U = u (x ) + y − d · S (x )

   wobei d der Schaden jeder zusätzlich produzierten Einheit auf die Umwelt ist
   (marginal damage).

Marktgleichgewicht

   Das Unternehmen wählt x so, dass sein Gewinn maximiert wird:
                                                max π (x ) = px − c (x )
                                                   x
   und die optimale Menge x ist gegeben durch die FOC:
                                                           c 0 (x ) = p
   Der Konsument wählt x so, dass er seinen Nutzen unter der Budgetrestriktion
   maximiert, wobei die produzierte Menge x̄ als gegeben betrachtet wird:
                          max U (x ) = u (x ) + y − d · x̄ s.t. px + y = m
                            x
   Nebenbedingung nach y auflösen, in Nutzenfunktion einsetzen:
                                     max U (x ) = u (x ) + m − px − d · x̄
                                        x
   (d · x̄ wird als gegeben betrachtet, geht nicht in Optimalitätsbedingung ein.)
   Die Nachfrage nach Gut x ist durch die FOC gegeben:
                                                           u 0 (x ) = p
   Im Marktgleichgewicht ist dann u 0 (x eq ) = peq = c 0 (x eq ).

Soziales Optimum

   Für die Gesamtwohlfahrt werden Nutzen des Konsumenten und Gewinn des
   Produzenten addiert:

            W = u (x ) + m − px − d · x + px − c (x ) = u (x ) + m − c (x ) − d · x

   Wenn man die Gesamtwohlfahrt maximiert, ist die sozial effiziente Menge x durch
   die FOC gegeben:
              dW
                 = u 0 (x eff ) − c 0 (x eff ) − d ≡ 0 ⇐⇒ u 0 (x eff ) = c 0 (x eff ) + d,
              dx
   während das Marktgleichgewicht durch u 0 (x eq ) = c 0 (x eq ) gegeben ist.
   Weil die Grenzkosten positiv sind (c 0 (x ) > 0), ist c 0 (x eff ) < c 0 (x eq ).
   Das heisst, die sozial effiziente Menge ist kleiner als die Gleichgewichtsmenge:
   x eff < x eq ; das Marktgleichgewicht führt zur Überproduktion von Gut x.
   Der effiziente Output wäre durch p = SMC (social marginal cost) gegeben, nicht
   durch p = MC (private Grenzkosten).

Negative Externalitäten: Lösungen

Möglichkeiten zur Internalisierung der Externalitäten:
    Durch Regulierung:, d.h. man limitiert Produktionsmengen. Dies ist ein Eingriff in
    den Marktmechanismus und erfordert Geld und Überwachung. Sinnvoll, wenn die
    Externalität reduziert werden soll, unabhängig von den Kosten der Reduktion.
    Durch Zuordnung von Eigentumsrechten (property rights) wird das öffentliche
    Gut in ein privates umgewandelt. Dann können die betroffenen Parteien
    (Verhandlungs-)lösungen finden können, um die Externalität zu internalisieren.
    (Coase-Theorem, siehe nächste Seite)
    Durch Ausgabe von handelbaren Zertifikaten an Verursacher, die die Menge der
    Externalitäten insgesamt steuert; z.B. Emissionszertifikate werden an Firmen
    vergeben, die diese Zertifikate dann untereinander handeln können, aber
    Gesamtmenge an Emissionen bleibt konstant.
    Durch Besteuerung der negativen Externalität (Pigou-Steuer, siehe Slides unten),
    so dass private und soziale Kosten gleich sind. Das schränkt die staatliche
    Intervention ein und lässt die Verursacher der Externalität für die sozialen Kosten
    aufkommen, die sie anderen auferlegen.

Korrektur von Externalitäten: Coase Theorem

Marktlösung, um externe Effekte zu internalisieren:
     Coase Theorem (Ronald Coase, 1960): Wenn die Eigentumsrechte (property rights) klar
     definiert sind, kann ohne staatliches Eingreifen eine sozial effiziente Allokation der
     Ressourcen erreicht werden.
     Die effiziente Lösung hängt nicht davon ab, bei wem die Eigentumsrechte liegen. Jedoch hat
     die Zuweisung, wer wen kompensiert, distributive Implikationen für die beiden Parteien.
     Beispiel: Wenn ein Fluss durch eine Fabrik verschmutzt wird:
          Wenn die Anwohner die Eigentumsrechte (Recht auf sauberes Wasser im Fluss)
          besitzt, wird der Produzent d für jede Einheit der Verschmutzung im Gleichgewicht
          bezahlen (durch Verhandlungen ins Gleichgewicht).
          Grenzkosten der Produktion sind dann c 0 (x ) + d, was zur effizienten
          Produktionsmenge x eff führt.
          Wenn der Produzent die Eigentumsrechte (Verschmutzungsrechte) besitzt, werden die
          Anwohner dafür bezahlen, dass weniger verschmutzt wird: u 0 (x ) = p + d.
     Coase-Theorem verbindet die externen Effekte mit dem Preismechanismus: Angebot und
     Nachfrage führen zu einem effizienten Ergebnis zu niedrigsten Kosten.

Coase-Theorem: Kritikpunkte


Schwierigkeiten in der Anwendung: Eigentumsrechte und Verhandlungslösungen
können problematisch sein.

    Zuweisung des Schadens: Identifzierung des Verursachers muss eindeutig
    möglich sein.
    Bestimmung des Grenzschadens: Anreiz der betroffenen Marktseite, den
    Schaden zu übertreiben.
    Problematik individuellen vs. kollektiven Handelns bei der Verhandlung: Mehrere
    Fischer als eine Verhandlungspartei kann Probleme darstellen.
        Falls Eigentumsrechte bei Fischern: Vetorechte können Verhandlungen blockieren;
        Interessenskonflikte bei Untergruppen.
        Falls Eigentumsrechte bei Produzent: Trittbrettfahrerproblem der Fischer kann
        Interesse der Fischer nicht genügend berücksichtigen.

    Transaktionskosten (höher je mehr Beteiligte) und Informationskosten (Vorteil auf
    Kosten der weniger informierten Seite) verursachen Probleme der Anwendung.

Staatliche Intervention: Pigou-Steuer



   Arthur-Cecil Pigou (1920): Steuer t auf die Produktion des Guts auferlegen, das
   Externalitäten verursacht
   t = Grenzschaden d, so dass die effiziente Menge x eff produziert wird und die
   Gesamtwohlfahrt maximiert wird.
   Besteuerung der Quelle negativer Externalitäten: Tabak-Steuer, CO2 -Steuer
   (Schweden 124 Euro/Tonne, Schweiz: 84 Euro, Finnland: 62 Euro, Österreich: 32
   Euro, Portugal: 7 Euro, Lettland: 5 Euro, Estland: 1,8 Euro)
   Subventionierung der Quelle positiver Externalitäten: Steuerliche Förderung von
   Forschung und Entwicklung
   Schwierigkeit der Anwendung: Grenzschadenfunktion muss bekannt und messbar
   sein (Schaden muss nicht linear sein).

Positive Externalitäten: Lösungen




Zwei Möglichkeiten für den Staat bei positiven Externalitäten und Unterpdroduktion:

    Pflicht: Schulbesuch (d.h. Ausbildung) ist Pflicht. Frage ist, wieviel Schulbildung
    genau Pflicht sein sollte, d.h. die Externalität ist nicht genau bekannt, und die
    sozial effiziente Menge daher auch nicht bestimmbar.
    Subventionen: Sie reduzieren den Preis für die Konsumenten und sollten daher
    die Nachfrage auf das sozial optimale Niveau anheben. Es müssen aber die
    Kosten der staatlichen Intervention mit dem Nutzen aus der verbesserten Effizienz
    abgewogen werden.
