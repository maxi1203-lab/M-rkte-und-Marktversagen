# Probeklausuren & Altklausuren

Pro Klausur ein Unterordner.

## Struktur pro Ordner

```
probeklausur-NN/
├── angabe.pdf
├── loesung.md           ← eigene Lösung unter Zeitdruck
├── musterloesung.pdf    ← falls verfügbar
└── retro.md             ← Review nach dem Durchlauf
```

## Empfohlener Workflow

1. **Simulation unter Zeitdruck** (z.B. 90 Min), kein Skript, kein Claude.
2. Eigene Lösung einscannen/abtippen in `loesung.md`.
3. Mit Musterlösung abgleichen.
4. `retro.md` ausfüllen:
   - Was saß? Was nicht?
   - Welche Themen nochmal?
   - Typische Formulierungen merken.

## Altklausuren

In `altklausuren/` — wenn nur Fragensammlung / Erinnerungsprotokolle
vorliegen, als `gedaechtnisprotokoll-YYYY-SS.md` ablegen.
