# Zusatz-Übungen

Aufgaben, die **nicht** Teil der offiziellen Hausübungen sind, aber zum
Üben hilfreich:

- Aufgaben aus Lehrbüchern (Varian, Pindyck/Rubinfeld, ...)
- Klausur-artige Extra-Aufgaben (von Claude generiert oder aus dem Netz)
- Spezifische Schwächen-Drills

## Dateinamen

`<thema>-<quelle>-<kurztitel>.md`, z.B.
`externalitaeten-varian-kap34-aufg3.md`.
